# sistema-pedidos-java
sistema de pedidos de hamburgueria desenvolvido em java para praticar lógica de programaçao.
o sistema simula o atendimento de uma hamburgueria pelo terminal, permitindo que o usuario selecione os produtos, qual a quantidade e visualize o total do pedido.



*funcionalidades*
exibe um cardapio com nome do produto e preço do produto.
seleciona o produto pelo nome ( voce pode digitar tanto com letra minuscula como maiscula que o programa vai entender). 
dá a opçao de escolher a quantidade desejada.
calculo do subtotal dos produtos
permite que voce avance caso precise de mais alguma coisa, ou se nao precisar, será direcionado ao total do pedido.



*tecnologia e conceitos usado*
linguagem java
VScode
variaveis e tipos de dados
estruturas condicinais ( if, else if, else )
estrutura de repetiçao ( while )
metodos e parametros
entrada de dados com Scanner
